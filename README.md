## About

I have 10+ years of Java experience and work across the stack—from backend services and APIs to polished interfaces and deployment. These days I build with **Java, Go, Python, React, TypeScript, Flutter, Tauri, and Rust**.

我的个人项目主要围绕本地优先体验、内容阅读、媒体整理，以及新加坡日常生活中的小问题。大部分项目是业余作品，欢迎试用、提建议或交流实现方式。
